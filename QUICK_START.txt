📋 WHAT YOU BUILT:
  ✓ Full-stack blogging platform (6 files)
  ✓ React frontend + Express backend + SQLite
  ✓ User auth, posts, comments

🚀 GET STARTED IN 3 STEPS:

  1. Install dependencies
     npm install

  2. Terminal 1: Start backend
     npm start
     → Server runs on http://localhost:5000

  3. Terminal 2: Start frontend  
     npm run client
     → App opens at http://localhost:3000

📁 THE 6 FILES:

  1. server.js              (200 lines) - Express backend with SQLite
  2. src/App.jsx            (380 lines) - React frontend (all views)
  3. src/App.css            (400 lines) - Complete styling
  4. src/index.jsx          (15 lines)  - React entry point
  5. public/index.html      (10 lines)  - HTML root
  6. package.json           - Dependencies & scripts

🎯 QUICK FEATURES TEST:

  1. Register new account (click "Register")
  2. Create a post (click "+ New Post")
  3. Read posts & add comments
  4. Manage your content (delete posts/comments)

🔧 USEFUL COMMANDS:

  npm start              → Start backend server
  npm run client         → Start React frontend
  npm run dev            → Backend with auto-restart (needs nodemon)
  npm run build          → Production React build

⚠️  COMMON ISSUES:

  Port 5000 in use?
    lsof -ti:5000 | xargs kill -9

  Port 3000 in use?
    lsof -ti:3000 | xargs kill -9

  CORS error?
    → Backend must run on port 5000
    → Restart both servers

  Login not working?
    → localStorage.clear()
    → Try again

🔑 API ENDPOINTS (15 TOTAL):

  Auth (2):
    POST /api/auth/register
    POST /api/auth/login

  Posts (5):
    GET    /api/posts
    GET    /api/posts/:id
    POST   /api/posts           [AUTH]
    PUT    /api/posts/:id       [AUTH]
    DELETE /api/posts/:id       [AUTH]

  Comments (2):
    POST   /api/posts/:postId/comments  [AUTH]
    DELETE /api/comments/:id            [AUTH]

  [AUTH] = Requires JWT token

  • Change to persistent DB: sqlite3.Database('./blog.db')

  • Test API calls with Postman or cURL
  • Check browser console (F12) for errors
  • Check server console (terminal 1) for server logs
